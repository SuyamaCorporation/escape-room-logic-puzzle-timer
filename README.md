## Escape Room Logic Puzzle Timer & Hint System

Five sequential logic puzzles (digit sum cipher, color sequence initials, word anagram, algebra equation, and a final combination lock) with a 60-minute countdown timer. Each puzzle has three hint levels that can be unlocked one at a time, each costing 5 minutes off the clock. A completion screen shows time elapsed and hints used.

**Tech:** Vanilla JS, Tailwind CSS CDN, real-time interval-based countdown timer.

**How to use:** Type your answer in the input field and press Submit or Enter. If stuck, click "Use Hint" to reveal a progressive hint at the cost of 5 minutes. Complete all 5 puzzles before the clock hits zero to escape!
